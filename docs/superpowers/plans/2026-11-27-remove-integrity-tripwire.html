Goal

Remove the hook and settings integrity tripwire and the MEMORY.md quarantine from jacked, in one pull request. After the change, jacked does not snapshot settings.json, does not compare hook scripts, does not add an integrity block at session start, and does not move lines out of a memory file.

The owner chose this in the question dialog on 2026-11-27: "Rip it out". The option text was: "Delete the tripwire, the session-start block, the MEMORY.md quarantine, the baseline file, the doctor line, the dashboard panel and the rules sentence, with their tests and docs, in one PR. A user's existing ~/.claude/jacked/integrity.json is removed at install. Close #324i as won't-do."

Why

The owner did not ask for the tripwire. A Claude session filed #99i on 2026-08-02 after a research pass, and a backlog batch built it as milestone M14 (#276pr, release 0.111.0). It warns at each session start about changes that Claude Code, the user or an installer that the user ran made. The owner said: "you are thinking you are some type of gatekeeper ... did i ask for it or scope creep?"

Cleanup of old baseline files

  • jacked install (which an upgrade runs) and jacked uninstall remove these two files.
  • Remove only these two exact names. Use lstat: do not follow a link, and do not remove a folder that has the name of a file.
  • Remove the jacked/ folder only when it is empty after that. A user file in it stays, and so does the folder.
  • Print one line for each file that you removed. A missing file gives no line. An error gives one warning line and does not stop the install.
