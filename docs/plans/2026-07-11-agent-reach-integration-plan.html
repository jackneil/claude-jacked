Dispatch strategy

Per session chain-of-command: main loop (Fable) authors specs/prompts, verifies every diff, runs gates; coding milestones dispatch to Opus agents with explicit escalation instructions (stop and report on any design decision the spec doesn't cover). M1+M2 sequential (M2 consumes M1's pin schema); M3 after M2 (imports runner); M4 after M3 (calls API); M5/M6 parallelizable after M2. /cso security review runs on Fable per policy. Live E2E (M7) runs from the main loop, never delegated.
